# Feedback Management System

## Project Description
A web-based Feedback Management System developed using Java Servlets and JSP. Users can submit their name, email, and feedback message. Submitted feedback is displayed on a web page.

## Technologies Used
- Java
- JSP
- Jakarta Servlets
- Apache Tomcat 11
- Maven
- HTML and CSS

## Features
- Submit feedback through a web form.
- Process form data using a Servlet.
- Store feedback in an in-memory list.
- Display submitted feedback.
- Submit multiple feedback entries.

## How to Run
1. Import the project into Eclipse.
2. Update the Maven project.
3. Configure Apache Tomcat 11.
4. Run the project on the server.
5. Open `feedback.jsp` in the browser.
6. Submit feedback and view the results.

## Storage
Feedback is stored temporarily in memory and is cleared when the application restarts.
